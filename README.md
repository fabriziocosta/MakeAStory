# Story Dice

Roll a handful of emoji dice and turn the unexpected ingredients into a story.

## Try it

[Open Story Dice on GitHub Pages](https://fabriziocosta.github.io/MakeAStory/)

## Features

- Choose between 3 and 12 dice
- Adventure, Whimsy, and Mystery emoji packs
- Animated rolls and rerolls
- Generated story starters
- Copy the story prompt with one click

The app is a single static `index.html` file and needs no build step.
